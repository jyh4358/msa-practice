📚 ShopSaga — MSA 핸즈온 학습 문서

Spring Cloud로 마이크로서비스를 한 단계씩 직접 만들며 트레이드오프를 배우는 학습 프로젝트의 문서 모음입니다. 왼쪽 사이드바 또는 아래 카드에서 문서를 선택하세요. 각 페이지는 서버 없이 더블클릭으로 열립니다.

현재 상태: Phase 19 완료 — 6개 런타임 서비스(도메인 3 + gateway + auth + query)가 Kafka Saga·Outbox·CQRS 위에서 동작하고, k8s(kind)에 Kustomize 로 선언 배포되며, CI가 만든 이미지를 Argo CD 가 Git 을 보고 스스로 배포합니다. 남은 주제는 BACKLOG 참고.

🧭 처음이라면: 사이드바의 "Phase 단계별"을 위에서 아래로 순서대로 읽으세요. 각 문서 하단의 이전/다음 버튼(키보드 ←/→)으로 이어 읽을 수 있고, 복습은 각 문서 끝의 복습 포인트와 "지도·복습" 그룹의 파트별 복습 문서를 이용하세요.

Phase 단계별

Phase 0 · 스캐폴드
모노레포·버전 카탈로그·Flyway·동작 증명
Phase 1 · 모놀리스(ACID)
단일 트랜잭션·비관적 락·QueryDSL·헥사고날
Phase 2 · 결제 분리
payment 분리 + 원격 REST (단일 트랜잭션 소멸)
Phase 3 · API 게이트웨이
Spring Cloud Gateway 단일 진입점
Phase 4 · 서비스 디스커버리
Eureka 등록/조회·클라이언트 사이드 LB
Phase 5 · 보안(JWT)
RS256 JWT 인증·역할 인가·토큰 전파
Phase 6 · 중앙 설정
Spring Cloud Config + 시크릿 암호화
Phase 7 · Docker Compose
전체 스택 컨테이너 기동·서비스명 DNS
Phase 8 · 관측성
분산 트레이싱·메트릭 (OTLP → otel-lgtm)
Phase 9 · 비동기(Kafka)
재고 분리·OrderPlaced 이벤트·HTTP→Kafka 트레이스·리플레이
Phase 10 · Outbox+멱등성
트랜잭셔널 Outbox·@Scheduled 릴레이·멱등 소비자(effectively-once)
Phase 11 · CQRS 읽기 모델
이벤트 투영·MongoDB 읽기 모델·결정성·리플레이로 재구축
Phase 12 · Saga(보상)
코레오그래피·보상(semantic undo)·주문 상태기계·Saga 한 트레이스
Phase 13 · Saga 오케스트레이션
중앙 조정자·saga_instance·타임아웃 sweep·커맨드 멱등·모드 토글
Phase 14 · 복원력 패턴
Resilience4j 5종·게이트웨이 회로차단기·DLQ/poison·outbox 격리·고아 결제 보상
Phase 15 · 강화(계약·Bus)
Spring Cloud Bus 설정 방송·계약 테스트(동기 API+이벤트)·이벤트 스키마 진화
Phase 16 · 로컬 k8s(kind)
16a 클러스터+서비스 이전(probe·ConfigMap/Secret) / 16b Eureka·Config Server 삭제·Ingress·전체 플랫폼
Phase 17 · CI/CD
GitHub Actions·jar 1회 빌드·네이티브 러너 2개 멀티아치·GHCR·CI 안 kind 스모크 배포
Phase 18 · 선언적 배포
Kustomize base/overlay·생성기 해시로 설정 변경 자동 롤아웃·CI의 sed 제거·ingress-nginx를 Helm 릴리스로
Phase 19 · GitOps
Argo CD·CI→Git 승격 루프·selfHeal로 드리프트 복원·prune·비밀을 렌더 밖으로
